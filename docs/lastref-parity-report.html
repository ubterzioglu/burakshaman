1. Genel Özet

Amaç, iki projeyi fonksiyonel olarak eşitlemekti. Referans (ref/) klasöründe SQL/WXR dökümü yoktu; ancak site WP Rocket ile çalıştığından tüm sayfalar cache'te tam olarak render edilmiş HTML olarak duruyordu (ref/_/public_html/wp-content/cache/wp-rocket/…). Bu sayede gerçek içerik (bloglar, ürünler, sayfalar, etkinlikler, eğitmen ve görseller) çıkarılıp yeni içerik modeline aktarıldı.

Bu turda tamamlanan ana başlıklar: çift dilli (TR/EN) yapı, gerçek içerik göçü, sepet + çok kalemli PayTR ödemesi, etkinlik detay + biletleme, eğitmen profilleri, mobil menü / WhatsApp butonu ve veri modelinin genişletilmesi. Proje boyunca build ve lint yeşil tutuldu; commit atılmadı, silme yapılmadı (sayfalar yalnızca [locale]/ altına taşındı).

4. Bu Turda Tamamlananlar

Çift dilli yapı (TR + EN) Tamamlandı

  • Tüm sayfalar src/app/[locale]/ altına taşındı; src/proxy.ts yerel ön ek olmayan istekleri varsayılan dile (TR) yönlendiriyor.
  • Sözlük tabanlı arayüz çevirisi (src/lib/i18n/), LocaleSwitcher (TR/EN) header'da; footer/header/kartlar dile duyarlı.
  • Doğrulandı: / → /tr, /tr Türkçe, /en İngilizce arayüz.

Gerçek içerik göçü Tamamlandı

  • WP Rocket HTML cache'inden çıkarıcı script (scripts/extract-content.ts, build-content-data.ts) ile: 18 blog yazısı, 6 ürün (fiyatlarıyla), 5 etkinlik, 10+ sayfa, 1 eğitmen profili ve ~20 görsel (public/assets/wp/).
  • İçerik HTML olarak temizlenip (WPBakery sarmalayıcıları ve inline stiller çıkarıldı) content-data.ts → content.ts (statik fallback) ve prisma/seed.ts'e (DB) aktarıldı.
  • Blog gövdesi artık tek <p> değil, güvenli HTML olarak render ediliyor (HtmlContent). Türkçe slug'lar korundu.

Mağaza: sepet + çok kalemli ödeme Tamamlandı

  • İstemci sepeti (src/lib/cart.tsx, localStorage), header'da mini-cart rozeti, /cart ve /checkout sayfaları.
  • Ürün sayfasında "Sepete Ekle" / "Satın Al"; checkout tek PayTR token ile çok kalemli sepeti işliyor.
  • Hata giderildi: checkout eskiden statik content.ts'e göre doğruluyordu; artık DB ürünlerini kullanıyor.

Etkinlik detay + biletleme Tamamlandı

  • Etkinlik arşivi görselli kartlara dönüştü; /events/[slug] detay sayfası (görsel + içerik) eklendi.
  • Bilet oluşturma: /api/events/[slug]/tickets benzersiz kodlu Ticket kayıtları üretir ve e-posta gönderir.

Eğitmenler, ana sayfa, chrome Tamamlandı

  • Eğitmen dizini + profil sayfaları (/trainers, /trainers/[slug]).
  • Ana sayfa gerçek Türkçe içerikle yeniden düzenlendi; başlıklar/hero dile duyarlı; etkinlik/blog bölümleri gerçek verilerle.
  • Mobil navigasyon menüsü, sticky WhatsApp butonu, hesap sayfası başlık hatası düzeltildi.

Veri modeli genişletildi Tamamlandı

Prisma şemasına eklenen modeller (parite için, EN çeviri alanlarıyla): Trainer, Level, Room, Class, EventSession, Ticket, ServiceCategory, Service, AvailabilitySlot, PostComment, Testimonial, MembershipPlan; Event/Product/Post/Page alanları genişletildi.

7. Tamamlanamayan / Emin Olunamayan Noktalar

  • Ders programı verisi: Site esasen koçluk/danışmanlık odaklı; cache'te helix "class" haftalık program verisi yok. Takvim özelliği kod olarak hazır fakat besleyecek veri yok.
  • Etkinlik tarih/oturum/harita detayları: Etkinlik başlığı, görseli ve gövdesi güvenle çıkarıldı; kesin tarih, oturum tablosu ve harita koordinatları helix/EventPrime karışık işaretlemesi nedeniyle kısmen elde edildi.
  • Sadece DB'de olan içerik: WP Rocket tarafından hiç cache'lenmemiş (yayında olmayan/az ziyaret edilen) sayfalar dosyalardan kurtarılamaz; yalnızca gerçek bir DB dump ile gelir.
  • WooCommerce geçmişi: Eski müşteri/sipariş/indirilebilir ürün geçmişi dump olmadan aktarılamadı (yeni model hazır).

9. Riskler ve Önerilen Sonraki Adımlar

  • Veritabanı göçü: Şemaya çok sayıda model eklendi. Supabase'de npx prisma migrate deploy ve npm run db:seed çalıştırılmalı (seed aynı gerçek içeriği yükler). Yerelde DB olmadığından uygulama fallback içerikle çalışıyor.
  • PayTR: Test modunda (PAYTR_TEST_MODE=1). Canlıya almadan uçtan uca token akışı doğrulanmalı; okUrl/failUrl artık /tr/….
  • EN içerik: Arayüz TR/EN; içerik TR tam, EN kısmi. EN sayfaların manuel çevirisi önerilir.
  • Bilet QR görseli: qrcode paketi eklenip bilet kodları QR olarak render edilebilir.
  • Sonraki fazlar: Admin tam CRUD arayüzü, slot bazlı randevu seçici, blog yorum formu, (veri gelirse) ders programı takvimi.
  • Doğrulama: npm run build ve npx eslint src yeşil; TR/EN ana sayfa, mağaza+ürün, blog+yazı, etkinlik+detay+bilet, eğitmen, sepet, checkout, hesap ve admin login route'ları 200 döndü.
